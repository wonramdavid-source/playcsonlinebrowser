## 📖 项目简介

**铁潮 (IRON TIDE)** 是一款基于 WebGL 技术开发的免费在线 CS 风格网页第一人称射击（FPS）游戏。

玩家无需下载安装庞大的客户端，也不需要注册账号，只需使用电脑浏览器搭配键盘和鼠标，即可随时随地体验硬核、爽快的射击对战。

> **免责声明**：本项目为独立开发的 CS 风格网页版游戏，并非 Valve 官方产品，亦非 CS 1.6 的完整移植。部分经典地图使用了 CS 1.6 相关素材，实际武器弹道、规则机制以本游戏内体验为准。

## ✨ 核心特色

- **免安装 / 免注册**：打开网页秒进大厅，本地缓存与轻量加载。
- **多人联机**：支持一键快速匹配在线对局，或自建房间分享专属链接/房间码邀请好友组队。
- **单人 AI 训练**：支持离线级体验的单机模式，自由调节机器人（Bot）数量与难度，适合练习压枪（AK-47 / M4A1-S）与架狙（AWP）。
- **多种特色模式**：
  - **经典爆破**：装包、拆包、战术攻防。
  - **快节奏交火 / 死斗**：经典复刻地图的短兵相接。
  - **人质解救**：经典反恐救援玩法。
  - **丧尸模式（合作防守）**：支持组队合作抵挡 30 波尸潮进攻。
  - **丧尸模式（经典感染）**：开局随机产生母体丧尸，展开人类与丧尸阵营的感染攻防。

## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q1: 手机或平板可以玩吗？</b></summary>
当前游戏核心玩法基于键鼠射击与 WebGL2 渲染开发，目前主要面向电脑端玩家，移动端体验受限。
</details>

<details>
<summary><b>Q2: 一个人可以单独玩吗？</b></summary>
可以。在大厅选择「单机模式」，设置 AI 人数与难度后即可直接开始，无需等待匹配。经典丧尸模式单人游玩时请确保勾选添加 AI。
</details>

<details>
<summary><b>Q3: 游戏进度和战绩保存在哪里？</b></summary>
玩家的个人等级、勋章及战绩记录默认保存在当前浏览器的本地存储（Local Storage / IndexedDB）中。清理浏览器缓存或更换设备将不会自动同步。
</details>

## 🛠️ 技术栈参考

- **核心渲染引擎**：Three.js (`WebGL2`)
- **前端框架/构建工具**：Vite / ES Modules
- **核心逻辑**：自定义导航网格寻路（Navigation Mesh）、多边形碰撞检测（Collision System）
